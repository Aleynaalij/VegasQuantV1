# Accounts and friends passes

Verified administrators can open /admin/accounts to search registered accounts and copy the private friends code. No credentials or MFA secrets are returned by the account listing.

The randomly generated code is kept in the private database, never bundled with the website or checked into Git. It grants a full 2026 season membership ending February 16, 2027 at 12:00 UTC, including playoffs and Super Bowl. No payment is required. Capacity is 10 successful distinct-account redemptions. A promo-row lock and user advisory lock serialize competing claims; duplicate claims do not consume additional capacity. Active members and administrators do not consume capacity. Attempts are limited to five per confirmed account per 15 minutes. Expired or disabled offers reject new claims.

Friends may enter the code at signup, confirm email, sign in, then activate the code from Account. Signup code is retained only in sessionStorage on the same browser tab; on another device they must reenter it. Registration does not reserve capacity. Anyone with the code can claim until exhausted; one-account enforcement does not prevent a person from creating multiple accounts.

Redemptions permanently reference the granted membership. No betting records are modified.
