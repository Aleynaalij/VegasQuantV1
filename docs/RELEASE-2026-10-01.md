## Matchups

`/matchups` searches team names, abbreviations, week, date and game window. Existing `/games` links redirect. Each fixture has a permanent `/matchups/[slug]` URL. Public users see schedule; research requires membership. Mobile defaults to upcoming week.

`/admin/matchups` publishes supplied analyst updates with preview. A new immutable version stores the original handoff and structured snapshot. Missing sections carry forward unchanged; empty arrays explicitly clear a section. Targets are full replacement arrays. Next review does not carry forward automatically. Later updates require what changed and analyst response.

Structured fields: market, model, injuries, teams, weather, vegas, bias, sections, targets. Targets support rank only when the analyst supplies it. An OFFICIAL target must link an existing official pick with matching game and selection; this workflow cannot create picks or change bankrolls.

All schedule entries begin without invented analysis. The original Steelers/Browns analysis and official pick remain preserved. No example targets from the feature specification were seeded.

## Automated sources

Supabase Edge Function `source-sync` uses custom bearer-token authentication, checking a SHA-256 digest stored in a private server-only table. Its high-entropy token is held in Supabase Vault, not Git or browser code. A 15-minute pg_cron job invokes it.

ESPN public endpoints supply schedule, scores, injury statuses and linked news headlines. The endpoints are not a contracted guaranteed feed: errors retain previous snapshots and are reported in `/admin/feeds`. Source data does not become Vegas Quant analysis. Provider timestamps remain distinct from retrieval times. Schedule changes cannot overwrite games with published official picks. TBD times remain labeled TBD.

An optional The Odds API adapter covers FanDuel/DraftKings spreads, moneylines and totals. It requires ODDS_API_KEY and ODDS_FEED_ENABLED=true in Supabase Edge Function secrets, plus the owner's suitable provider plan. No key is committed. Betting splits, independently verified sharp books, comprehensive weather forecasting, and exact player-prop closing feeds still require suitable provider coverage. Missing feeds do not produce estimates.

No automatic wager settlement: final game scores cannot resolve a player prop or sportsbook-specific void rule. Official results and closes remain reviewed publications. Automated source observations and private tapes preserve raw facts for that review.

The home official slip is always expanded. Entry recording remains in the single personal bankroll path.
