# October 31 Home performance and college moneylines

The post-release owner report was slow/glitchy navigation and missing college moneyline reads. Member `sports_slate` responses measured 4,418,162 bytes for NHL (4,049,796 bytes of facts) and724,978 for college (343,605 facts). Home did not use those facts. College also mounted380 hidden game panels and SportDesk re-sorted every market for every game.

New read-only SECURITY INVOKER `sports_home` returns the same schedule, latest exact market snapshots and bound editorial selections without scanning facts or results. Existing `sports_slate`, `sports_game`, RLS, age rules, source collectors, publication and result paths remain intact. Actual authenticated reads after applying the additive migration: NHL371,170 bytes, college381,377; facts/results empty. Anonymous schedule remains visible, protected arrays empty. This measures JSON payload size, not a latency guarantee.

Home and sport Slots use the lighter read. Home derives grouped moneylines once, ignores same-account auth refresh events, renders32 rows initially, exposes the rest with Show more, mounts market panels only when opened and disables matchup-link prefetch. No account-private cache is introduced. All fixtures remain reachable; publication and random-ticket freshness gates stay strict.

The college source had eight h2h prices across four of380 upcoming games at diagnosis, all expired by the30-minute quote window. That is a coverage gap, not380 model edges. Home now displays valid stored two-sided snapshots with their observation time; expired snapshots explicitly say Older quote and Market lean · snapshot. It never substitutes recorded_at for source time, accepts unknown/future timestamps, or pairs a removed outcome with an older opposing side. Current-only `sportFace` and Slots retain expiry rejection. Coverage count and copy explain that the lean comes from sportsbook prices and is not an independent model edge. Missing games get no invented numbers. No provider spending or cadence changed.

Validation includes SQL role/age isolation, latest/bound quote preservation without a facts/results table, stale/unknown/incomplete-side tests,390/1280 browser tests for380 games/32 initial rows/lazy panels/show-all reachability and visible expiry during an outage.
