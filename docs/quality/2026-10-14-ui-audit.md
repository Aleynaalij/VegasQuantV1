# UI audit — October 14, 2026

Scope: every public route at phone (390px) and desktop (1280px) widths, light and dark themes, plus Supabase security/performance advisors. Published picks, records, prices, bankrolls and analysis text are unchanged.

## Corrected

- **Readability floor.** 165 CSS declarations set text at 7–10px (footer, mobile tab labels, sidebar labels, badges, timestamps). All text is now at least 11px; only the unread-count bubble on the bell stays at 10px to fit its circle.
- **Membership page contrast.** The season pass and monthly cards still used dark-theme green backgrounds on the light theme, which left the plan names nearly invisible (1.07:1). The cards, "Email"/"Password" labels (1.45:1), "New here? Create an account" (1.72:1) and "What is Vegas Quant?" (1.53:1) now meet WCAG AA in both themes. Disabled "Checkout coming soon" buttons now look disabled.
- **Dark-theme contrast.** Skip link, selected NFL/NBA switch, footer, the Zone schedule note and "Previous tickets" link were below AA in dark mode; fixed.
- **Error page.** A failed page load showed a bare "desk hit a snag" screen with no header or navigation. It now renders inside the normal app shell with Try again and a way out.
- **404 page.** Unknown links showed Next.js's default unstyled 404. There is now a branded page with links to the NFL desk, NBA desk and Records.
- **NBA desk layout.** "Building toward opening night" rows sat flush against the card edge and the "What we'll study" cards collided with their panel border; both have proper inner spacing. NBA pages no longer show the NFL 5-Spot footer disclaimer, and the breadcrumb reads "NBA desk".
- **Navigation state.** Methodology highlighted "Home" in the tab bar; it now shows no active tab and a "Methodology" breadcrumb.
- **Saved legs, signed out.** Signed-out visitors saw a search box, filters and "0 publication snapshots" before a plain-text sign-in note. They now see a single sign-in link; the board and counts appear after sign-in and once loading finishes.
- **Mobile footer.** Left-aligned instead of a mixed centered/left layout.

## Validation

- TypeScript, production build and all 70 automated tests pass.
- Automated WCAG contrast scan (every text node vs. its rendered background) reports zero failures on Membership, NBA, Feed, Saved, Methodology, error and 404 pages in both themes.
- No horizontal scroll at 390px on any reviewed page.

## Not covered / follow-up

- The audit environment cannot reach the Supabase API or vegasquant.app, so Home, Records, Matchups, Performance, game and community pages were not seen with live data. Their shared styles (fonts, footer, shell, contrast) were fixed globally; a live visual pass is still needed.
- Supabase: enable **Leaked password protection** (Auth settings). Ten foreign keys lack covering indexes and 19 indexes are unused (low impact at current volume). `enable_health_push` is flagged as callable by signed-in users; it is admin-gated and owner-scoped, so this is intentional.
- Naming: the desktop sidebar says "Game board" while the phone tab bar says "Analysis" for the same page. Pick one.
