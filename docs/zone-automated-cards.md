# Automated Zone publication cards

Owner request, Oct 31: automated posts from MikeQ must use the existing Vegas Quant research-card visual standard, with NFL blue, NHL red, college basketball green and NBA gold. Claude review is explicitly waived for this change while Claude is unavailable.

`ZonePublicationCard` reuses the original monogram, Barlow Condensed/DM Sans typography, black background, rounded frame and 1080×1350 format. It adapts the heading and accent to the sport and preserves the entire post across readable pages. Each page downloads as a branded PNG. The original `/api/nba/threes-card/[day]` renderer and daily `nba-threes` marker are unchanged.

The card appears in the existing single Zone feed, including sport filters. Full original analysis and sources remain available below it. Copy picks keeps the published title/matchup context alongside stored `legs`, and never extracts recommendations from arbitrary prose. Open with Gambly reuses the existing 21+ confirmation, explicit clipboard action, paste instructions and destination validation. Non-pick updates have no fabricated picks or Gambly controls. Member posts keep their current presentation.

The migration attaches `vq-publication:v1` only to new server publications running with both the `postgres` publisher role and `postgres` database session (the existing direct server/cron publication path) for the configured, verified MikeQ account. REST authenticator sessions calling manual share RPCs are excluded, even when those RPCs use SECURITY DEFINER. A separate early role/session return prevents ordinary member inserts from querying private configuration. The existing insert guard rejects members/service_role trying to supply this marker. Existing publisher functions, quote/evidence/profile/age checks, transaction claims restoration, idempotency, records and schedules are not replaced or bypassed.

Copyable NBA and NHL/college legs are attached only when an immutable journal entry matches the post (including original publication time and analysis/risk content); NBA also matches the deterministic publication ID and unknowns. Existing explicit legs are preserved. Backfill updates only proven editorial posts in place: it does not publish new picks, change analysis/prices/timestamps, convert MikeQ's manual posts, or alter comments/likes. Unjournaled automated updates can still get a branded card, but no inferred picks.

Validation includes PGlite role/provenance/backfill/future-publication tests, complete-content pagination tests, and actual app browser tests at 390/1280px for all sport colors, text bounds on every page, clipboard content, exported PNG dimensions, Gambly age gate and unchanged manual/threes cards. Production verification must compare original bodies, timestamps, publisher definitions, post IDs/counts, private privileges and original threes data before/after applying only this migration.
